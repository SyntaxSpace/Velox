# About Velox

Velox is a cloud-based smart printing platform that modernizes the traditional workflow of photocopy and print shops.

Instead of relying on WhatsApp, manual communication, and unorganized printing queues, Velox provides a structured digital workflow where customers can upload documents, configure print settings, complete payments, and track their order in real time.

Velox is designed to reduce friction for customers while improving operational efficiency for print shop owners.

---

# The Problem

Traditional print shops still rely on highly manual workflows.

Typical workflow:

- Customer shares document through WhatsApp
- Shop owner downloads the file
- Customer explains print settings manually
- Files become difficult to manage during rush hours
- Queue is invisible
- Privacy concerns due to permanent file storage

These problems increase waiting time and reduce operational efficiency.

---

# Our Solution

Velox replaces manual communication with a QR-based digital workflow.

Every shop receives a unique QR code.

Customers simply:

1. Scan QR Code
2. Upload Document
3. Configure Print Settings
4. Complete Payment
5. Join Live Queue
6. Track Order Status
7. Collect Print

The entire workflow becomes digital.
